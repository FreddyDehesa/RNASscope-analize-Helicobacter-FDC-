# RNASscope-analize-Helicobacter-FDC-
QuPath script for automated RNAscope analysis in Helicobacter spp. Detects red puncta using strict chromatic filters, performs cell segmentation, and quantifies signals per cell. Classifies cells as negative, 1+, 2+, or 3+, and computes global annotation percentages for objective and reproducible assessment.
